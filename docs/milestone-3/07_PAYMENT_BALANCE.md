# Phase 7 — Payment Balance

## Objective
Track remaining payment obligations for bookings using deposits or later collection.

## States
Support paid in full, deposit paid, balance due, paid outside Berthio, and payment link required.

## Handling
Support payment link before arrival and pay-on-site. Keep automatic collection future-ready only.

Overdue balances must warn staff, not auto-cancel bookings.

## Tests
Paid full, deposit/balance due, outside payment, overdue warning, tenant isolation.

## Done When
Staff can clearly see remaining balance and the next collection action.
